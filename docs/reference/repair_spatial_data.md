# Repair spatial data

Repair geometry in a spatial dataset.

## Usage

``` r
repair_spatial_data(x)
```

## Arguments

- x:

  [`sf::st_sf()`](https://r-spatial.github.io/sf/reference/sf.html)
  object.

## Value

[`sf::st_sf()`](https://r-spatial.github.io/sf/reference/sf.html)
object.

## Examples

``` r
path <- system.file("shape/nc.shp", package = "sf")
g <- sf::read_sf(path)
repair_spatial_data(g)
```
