# Import data

Import project data into the app.

## Usage

``` r
import_data(x, mode)
```

## Arguments

- x:

  `list` with project data.

- mode:

  `character` Mode for importing projects. Available options include:
  `"beginner"`, `"advanced"`, or `"project"`. Defaults to `"project"`.

## Value

Invisible `TRUE`.
