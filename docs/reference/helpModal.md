# Help modal

Constructs a modal for displaying helpful information.

## Usage

``` r
helpModal(id, trigger)
```

## Arguments

- id:

  `character` identifier for the modal.

- trigger:

  `character` identifier for the modal trigger. See
  [shinyBS::bsModal](https://rdrr.io/pkg/shinyBS/man/bsModal.html) for
  further details.

## Value

A `shiny.tag` object with the modal
