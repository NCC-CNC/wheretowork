# Import modal

Constructs a modal for importing data.

## Usage

``` r
importModal(id)
```

## Arguments

- id:

  `character` identifier.

## Value

A `shiny.tag` object.

## Examples

``` r
if (FALSE) { # \dontrun{
# run Shiny app to demo the sidebar pane
if (interactive()) {
  runExample("importModal")
}
} # }
```
