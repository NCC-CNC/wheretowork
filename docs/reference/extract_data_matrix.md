# Extract data matrix

Generate a `matrix` object containing data.

## Usage

``` r
extract_data_matrix(x)
```

## Arguments

- x:

  `list` of
  [Variable](https://ncc-cnc.github.io/wheretowork/reference/Variable.md)
  objects.

## Value

A `matrix` object.

## Details

Note that all variables must have the same
[Dataset](https://ncc-cnc.github.io/wheretowork/reference/Dataset.md)
object.
